==============================================================
== a named, non-DeepSeek provider, end to end
==============================================================
the provider is configured in moat's own store with its own key variable, then booted
with --provider. Before this phase the only route to another endpoint was --base-url, and
the box still described itself as DeepSeek in its config key, its provider label, its key
variable and the model catalog it was handed.
✓ configured provider acme at http://127.0.0.1:5687/v1

providers moat can be pointed at with --provider, or --base-url for one it does not know
  deepseek     https://api.deepseek.com           DeepSeek  (the default)
  acme         http://127.0.0.1:5687/v1           acme

  add one:   moat provider add <id> [--base-url <url>] [--env-var NAME] [--model ID]
             moat knows openrouter and openai by name and reads their endpoint and key variable from the model catalog.
             Anything else needs --base-url, because moat will not guess an endpoint for a name it does not know.
  use one:   moat up --provider <id> --model <id>
  remove:    moat provider remove <id>

  --env-var names the host variable holding the key. The value is never written to disk.
